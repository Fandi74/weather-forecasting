# V2 and V3 prediction comparison

The two images show frozen hourly forecasts for 3–9 November 2026 in WIB with
matching scales. V3 is the selected frozen CatBoost candidate, including V2/raw
fallback components identified in the graph footer and selected-methods JSON.
Actual measurements remain withheld. No model was refitted to draw the graphs.

graph_metadata.json preserves the original source identifiers, hashes and
workstation paths. original_build_graphs.py is the historical plotting script for
that workstation layout; the published PNGs are copied unchanged.
